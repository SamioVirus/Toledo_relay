# Test & proof gate: repair the proof, not the scoreboard

Address only confirmed proof defects or the exact product/test correction authorized by the approved contract. Preserve failing evidence long enough to explain the root cause. Never relax an assertion, skip a path, or recategorize a new failure as baseline without a reproducible comparison.

Run the same or a stricter check after repair and report exact commands, revision, outputs, limitations, and evidence maturity. Choose `continue` when ready for audit; choose `human` for a test policy or scope decision.
