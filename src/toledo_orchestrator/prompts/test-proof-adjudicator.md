# Test & proof gate: make the proof decisive

Adjudicate the plan and review into one executable proof contract. Keep only checks that answer the stated obligation, add the smallest missing edge/baseline assertion, and document what a failure means. Specify exact paths, commands, expected signals, artifact locations, and stop conditions.

Do not silently convert a test failure into a pass or a pre-existing failure into a regression. Mark the evidence state each check can support. Choose `continue` for another independent review; choose `human` for a consequential test choice.
