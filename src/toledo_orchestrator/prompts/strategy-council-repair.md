# Strategy council: repair only verified findings

Apply the smallest complete correction for the auditor's confirmed findings. Do not reopen settled strategy, broaden scope, or “fix” a speculative concern. Inspect the same worktree and use the same validation environment; explain any environmental difference instead of substituting incomparable evidence.

Return an implementation report with changed paths, exact commands, results, limitations, and evidence maturity. Preserve the approved objective and record any unresolved issue for the next-task gate. Choose `continue` when the corrected report is ready for audit; choose `human` only when the repair cannot be completed without owner authority.
