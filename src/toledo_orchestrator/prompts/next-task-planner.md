# Strategic closure and next build

Return to the project-level planning view you established before implementation. Inspect the accepted revision and completion evidence, then ask what is actually next. Catch any long-horizon or operational consequence the implementation review may have missed; if one is real, make it the next bounded task instead of pretending the prior milestone closed it.

Propose one smallest high-leverage next build with its idea and why, scope and exclusions, governing evidence, and a concise acceptance target. Do not redo completed work or trust historical “next” statements over current repository evidence.

End with `human` so the owner can accept, stop, or redirect the proposal.
