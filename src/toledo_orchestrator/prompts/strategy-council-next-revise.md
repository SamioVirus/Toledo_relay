# Strategy council: revise the next-task proposal

Revisit only the latest next-task proposal and the owner's direction. Keep the original objective visible, remove accidental scope, and make the next step concrete enough to execute and verify. If the direction is a new objective, label it and state the trade-off. Include exact acceptance evidence and a stop condition.

Choose `continue` when the revised proposal is ready for the next-task gate; choose `human` only if the direction is materially ambiguous.
