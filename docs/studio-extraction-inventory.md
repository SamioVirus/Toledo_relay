# Workflow Studio extraction inventory

This M0 inventory records the behavior extracted into the transport-first orchestrator and the archived systems deliberately left behind.

## Extracted

- Prompt bytes travel through stdin, never argv.
- Windows provider resolution prefers Claude's native executable and Codex's functioning npm shim.
- Provider stdout and stderr are captured as exact, separate byte artifacts before parsing.
- Codex JSONL and Claude JSON-envelope parsing are provider-local adapter concerns.
- Session identifiers, observed model metadata, timing, and reliable usage fields remain evidence, not route authority.
- Read-only provider permissions are explicit at invocation time.
- Strict prompts separate substantive work from a final, minimal process-control fence.
- Malformed control output receives one bounded, context-preserving correction attempt and then pauses.
- Model output cannot grant file, route, project, or permission authority.

## Retired from active development

- Canvas and graph authoring.
- Simple and pipeline graph engines.
- Schema-heavy content ports and model-output categorization.
- Browser, Google, Ollama, and five-provider workflow routes.
- Studio module-test write delivery as an orchestrator design pattern.

The archived Studio remains historical evidence. New capabilities must be justified by observed orchestrator pressure rather than copied wholesale.
