## 2026-07-14 — Operator-surface rescue: catalog on Windows, vertical preflight, Up Next gate, baseline-aware completion

- Root causes fixed, both verified live on this host. (1) Catalog discovery launched bare `codex`/`claude`; Python resolves those to the broken extensionless npm shims on Windows (`WinError 5`). Discovery now goes through `core.resolve_cli_executable` (`.cmd` → `.exe` → bare). (2) `text=True` subprocess capture decoded with the console codepage (cp1252); `codex debug models` contains UTF-8 punctuation, the reader thread raised `UnicodeDecodeError`, and stdout silently became `None`. Capture is now bytes decoded as UTF-8. After both fixes `codex debug models` returns six listable models (Sol/Terra now expose `max` and `ultra` efforts plus the `fast` speed tier); hidden `visibility!="list"` entries (codex-auto-review) are excluded. Curated Claude manifest refreshed to current official full IDs (fable-5, opus-4-8, sonnet-5, haiku-4-5-20251001; stale sonnet-4-6 dropped). A failed refresh is now persisted with per-provider errors instead of silently retrying discovery on every page load; engine-side validation reads the cached catalog only (`refresh=False`) so runs and tests never launch discovery subprocesses.
- New server-owned operator contracts: `GET /api/runs/<id>/next-turn` (read-only preview mirroring `advance` resolution: stage, resolved profile with one-turn override, session action, context inputs with sizes, humanized transitions, round usage, and the exact rendered transport prompt), `GET /api/workflows/<id>/stage-prompt?stage=` (exact static instruction bytes pre-launch), `POST /api/runs/<id>/stop` (deliberate operator finish → new `stopped` status, distinct from cancel), and `POST /api/runs` accepts `profile_overrides` that bind to the run snapshot only (validated against the catalog; saved defaults untouched).
- UI: preflight is a vertical editable stepper (per-stage who/model/effort/access/session, loop badges, produces/afterward sentences, exact-instruction view, per-profile run-only adjust with shared-stage warning; deduplicated warnings strip). The step gate is an Up Next dock (actor/model/effort/session, receives/produces/afterward/rounds, View exact prompt, inline Change model·effort·session reusing the override plumbing, one-turn guidance with explicit appended-not-replacing copy, per-stage Run button, Finish run). Settings split into Models (catalog status per provider with errors and refresh) / Route defaults / Projects tabs; per-card provenance text now appears only for explicit Custom selections.
- Completion semantics: when required validation fails at `@complete`, failures are fingerprinted (`FAILED/ERROR <nodeid>` identity, environment paths excluded) and compared against a lazily captured clean-base run executed in a disposable detached worktree (same environment kind as execution). All-unchanged-baseline failures pause at a new `validation_baseline_failure_decision` closure gate — accept with a sealed `baseline-debt` artifact (bound to base revision + patch hash + fingerprints) and commit, repair anyway, or stop without commit — instead of burning repair rounds on a failure the change did not introduce (the 2026-07-14 run's math-fixture worktree failure scenario).
